# 🪷 綠藝國際學苑 ╳ 老臣聊心室 ╳ 觀音靈籤身心靈調頻

> 「籤詩與吉凶，只是映照當下心境與盲點的『明鏡』，而非限制宿命的『框架』。真正的開運，在於透過靜心書寫梳理思緒、藉由綠植能量調和身心，由內而外活出從容自在。」

本專案由 **綠藝國際學苑 ╳ 老臣聊心室** 精心打造，結合傳統觀音一百靈籤、觀音心法覺察哲學與國際園藝治療專業，引導現代人透過沉浸式步驟沉澱雜念、請示指引，並獲得客製化的老臣靜心書寫題與五行綠植調頻處方。

---

## 🌟 核心功能特色

1. **慈悲觀音意象與心靈引言**：營造安定、溫暖的沉浸式沉靜氛圍。
2. **沉浸式求籤五步驟精靈 (Interactive Wizard)**：
   - 步驟一：洗手靜心（安頓身心呼吸）
   - 步驟二：唸誦聖號（互動計數累計滿 3 遍解鎖連結）
   - 步驟三：稟報資訊與明確祈求（姓名、生辰、地址、單一具體請示事項，附良好與避開範例）
   - 步驟四：點選抽籤（請示賜予靈籤）
   - 步驟五：線上擲筊確認天意（模擬聖筊、笑筊、陰筊機率；獲聖筊方解鎖解籤）
3. **四步驟解籤深度導航 ╳ 身心靈調頻處方**：
   - 步驟一：看「聖意/斷曰」（事業、婚姻、求財、健康、運勢、出行六大維度指引）
   - 步驟二：理解「籤詩故事」（歷史典故與處境投射啟示）
   - 步驟三：解讀「籤詩詩句」（四句古雅詩句排版與白話詩意）
   - 步驟四：老臣專屬身心靈調頻實踐（✍️ 靜心書寫提問 ╳ 🌿 國際園藝治療植物處方）
4. **手機與 LINE 內嵌瀏覽器 100% 相容**：
   - 全面採用 Streamlit 原生 `st.link_button(label, url, use_container_width=True)`。
   - 官方 LINE 連結支援原生 Universal Link Scheme：`https://line.me/R/ti/p/@mir4855b`。
5. **安全與隱私防護**：
   - 注入自訂 CSS 完全隱藏選單、頁尾與原始碼入口。
   - `.gitignore` 嚴格隔離所有多媒體素材與無關文稿。

## 🚀 本地啟動指南

```bash
# 1. 安裝相依套件
pip install -r requirements.txt

# 2. 啟動 Streamlit Web App
streamlit run app.py
```

瀏覽器將會自動開啟 `http://localhost:8501`。
